# Rosella language packs

Offline language packs for the Rosella phone app and sync server, published as releases (the app reads the latest release's `index.json`). Built with `tools/build_phone_packs.py` in the Rosella repo.

Dictionary and idioms: Wiktionary contributors (via Wiktextract / kaikki.org), CC BY-SA 4.0. Frequency lists: Hermit Dave, FrequencyWords (OpenSubtitles), CC BY-SA 4.0.
